# Degradation-Aware Semantic Segmentation

A modular semantic segmentation project organized for collaborative member development and model integration.

## Structure

- `data/`: Raw, processed, degraded, and mask datasets
- `members/`: Team-member implementation areas
- `integration/`: Full model, training, evaluation, and inference pipelines
- `notebooks/`: Exploratory and experimental notebooks
- `outputs/`: Generated feature maps, degradation maps, masks, and visualizations
- `checkpoints/`: Saved model weights
- `experiments/`: Baseline and proposed experiment configurations
- `docs/`: Architecture, methodology, and result documentation

## Setup

```bash
python -m pip install -r requirements.txt
```
